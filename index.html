How the Queue Works (FIFO)

FIFO = First In, First Out. The first order received is the first order prepared.

front = the index of the order that will be prepared next. rear = the index where the newest order is added.

enqueue() adds an order at the rear · dequeue() removes the order at the front · both take O(1) time (constant time).
